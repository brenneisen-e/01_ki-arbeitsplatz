# Edekabank – Modul (in Vorbereitung)

Dieser Ordner sammelt die Anforderungen und Assets für das zweite Modul
**Edekabank** der App „Bank der Zukunft 2035".

## Inhalt

- `images/` – Bilder/Screens für das Modul (PNG/JPG/SVG).
- Anforderungs-Dokument (`.md`) – wird hier abgelegt und beschreibt den
  fachlichen und visuellen Aufbau des Moduls.

Sobald Anforderung und Bilder vorliegen, wird das Modul auf Basis dieses
Ordners umgesetzt.
