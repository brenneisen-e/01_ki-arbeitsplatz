# Versicherungswissen

Wissensdatenbank rund um Versicherungsthemen für den KI-Arbeitsplatz.

## Struktur

Die Markdown-Dateien in diesem Ordner decken verschiedene Versicherungsbereiche ab:

| Bereich | Beschreibung |
|---------|-------------|
| Lebensversicherung | Kapitallebens-, Risikolebens- und Rentenversicherungen |
| Sachversicherung | Hausrat, Wohngebäude, Kfz |
| Krankenversicherung | Private und gesetzliche Krankenversicherung |
| Haftpflichtversicherung | Privathaftpflicht, Berufshaftpflicht |
| Berufsunfähigkeit | BU-Versicherung und Alternativen |
| Altersvorsorge | Riester, Rürup, bAV |

## Nutzung

Diese Dateien dienen als Referenzmaterial und Wissensbasis für die KI-gestützte Beratung im Versicherungsbereich.
