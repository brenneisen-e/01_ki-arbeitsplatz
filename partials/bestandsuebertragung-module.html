  • Go-Live Begleitung und Monitoring

ANNAHMEN

Annahmen & Risiken

Annahmen

  • Zugang zu repräsentativen E-Mail-Testdaten wird innerhalb Phase 1 bereitgestellt
  • Fachliche Ansprechpartner bei ERGO stehen für Workshops zur Verfügung (mind. 1 Tag/Woche)
  • Architekturentscheidung (Option 1/2A/2B) wird am Ende Phase 1 getroffen
  • Bei Option 2A: ERGO Agent-Plattform ist verfügbar oder wird parallel bereitgestellt

Risiken

  • Datenzugang: Verzögerung bei Testdaten kann PoC verschieben (+2–4 Wo.)
  • Datenschutz: Langwierige DSGVO-Abstimmung kann Phase 2/3 blockieren
  • Systemzugang: Fehlende API zum Postkorbsystem erfordert Workaround (Batch statt Echtzeit)
  • Scope Creep: Erweiterung auf weitere Dokumenttypen oder Sparten erhöht Aufwand
  • Erkennungsqualität: Handschriftliche Vollmachten können zusätzliche Nacharbeit erfordern

Parallel wird evaluiert, ob ein strukturiertes Formular und eine API als zusätzlicher Eingangskanal den Automatisierungsgrad weiter steigern können.

AUSGANGSLAGE (IST)

  • Sechsstellige Anzahl an BÜ-Vorgängen p.a. – die ERGO bearbeitet jährlich eine sechsstellige Anzahl an Bestandsübertragungen, die überwiegend als unstrukturierte E-Mails über Gruppenpostfächer eingehen
  • Überwiegend manuelle Bearbeitung – jeder Vorgang durchläuft 3–4 manuelle Prüfschritte inkl. Vollständigkeitsprüfung, Maklervollmacht und Vertragsnummernabgleich
  • ERGO GPT nur eingeschränkt nutzbar – die bestehende KI-Lösung verarbeitet ausschließlich einfache Text-E-Mails ohne Anhänge und deckt nur einen Bruchteil der Vorgänge ab
  • Unstrukturierte Eingangsdaten – Freitext-E-Mails, heterogene Anhänge (PDF, Word, Excel) und fehlende Standardisierung erschweren die automatisierte Verarbeitung

  • KI-Agent für unstrukturierte E-Mails – pragmatischer Einsatz eines KI-Agenten früh in der Prozesskette zur automatisierten Verarbeitung aller eingehenden E-Mails inkl. Anhänge (Word, Excel, PDF, Vollmachten)
  • Evaluierung: Strukturiertes Formular & API – im Projekt wird erarbeitet und bewertet, ob insbesondere Großmakler BÜ-Daten künftig über ein standardisiertes Online-Formular oder eine API liefern können und damit unstrukturierte Eingangsdaten an der Quelle reduziert werden
  • Hoher Automatisierungsgrad – Standardvorgänge vollautomatisch klassifiziert, extrahiert und an Robotics übergeben. Manuelle Prüfung nur noch für Sonderfälle

  • Durchlaufzeit von Tagen auf Minuten – KI-Erkennung von Vollmachten, automatisches Splitting von Multi-Verträgen und direkte JSON-Ausgabe für Robotics
